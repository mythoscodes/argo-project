현재 스프린트 진행 상황을 종합 리포트합니다.

## 점검 항목

1. **태스크 현황**: TaskList로 전체 태스크 상태 확인 (pending/in_progress/completed)
2. **구현 완료된 기능**: F1~F7 중 완료/진행중/미착수 구분
3. **구현 순서 준수 여부**: F1→F2→F3→F4→F5→F6→F7 순서 확인
4. **Git 상태**: 커밋 이력, 미커밋 변경사항
5. **빌드 상태**: 마지막 빌드 성공 여부
6. **AI 모델 상태**: 현재 사용 중인 모델 (옵션 A/B/C)
7. **데모 준비도**: 6단계 데모 시나리오 중 몇 단계까지 동작하는지

## 출력 형태

```
Day: X/9
기능 완료: F1 ✅ F2 ✅ F3 🔄 F4 ⬜ F5 ⬜ F6 ⬜ F7 ⬜

AI 모델: gemini-3-flash (옵션 A)

```
