# Argos 데모 시나리오 (심사위원용)

> **소요 시간**: 약 10분  
> **준비물**: 웹 브라우저 (Chrome 권장)  
> **접속 URL**: 배포된 Vercel URL

---

## 사전 준비

로그인 페이지 하단의 **"테스트 계정으로 체험하기"** 버튼을 클릭하면 데모 계정을 선택할 수 있습니다.  
모든 계정의 비밀번호는 `test1234` 입니다.

---

## 시나리오 1: 강사 — AI 실시간 수업 분석 (3분)

### 로그인
1. "테스트 계정으로 체험하기" → **김강사** 클릭 → 로그인

### 세션 확인
2. 세션 목록에서 기존 세션 3개 확인 (JPA / React / Python)
3. **"Python 데이터 전처리 실습"** (진행중) 클릭

### 라이브 대시보드 확인
4. 참여 코드, 참여자 5명, 응답 현황 확인
5. **"AI 퀴즈 생성"** 버튼 클릭 → AI가 5문제 자동 생성 (객관식 3 + 주관식 2)
6. 퀴즈 카드에서 문제 유형 Badge (출력 예측 / 버그 찾기), 오개념 태그 확인
7. **"분석하기"** 버튼 클릭 → 이해도 히트맵 + AI 코칭 생성
8. AI 코칭 패널에서 구조화된 코칭 확인:
   - 핵심 인사이트 (보라색 그라데이션 카드)
   - 취약 개념 + 오개념 상세
   - 비전공자/경력자 수준별 제안
   - 면접 팁
   - 오답 패턴 분석

### 리포트
9. "리포트" 버튼 → 라운드별 이해도 추이 차트 확인

---

## 시나리오 2: 수강생 — 퀴즈 응답 & 학습 리포트 (2분)

### 로그인
1. 로그아웃 → **이지수** (수강생, 주의) 로그인

### 내 수업 대시보드
2. 참여한 수업 3개 + 성적 요약 (평균 정답률, 최고 점수) 확인
3. AI 역량 진단 배너 확인
4. 종료된 수업 **"React Hooks 심화"** → **성적 확인** 클릭

### 결과 확인
5. 그라데이션 점수 카드 (정답률 %) + 토픽별 성적 바 차트 확인
6. **"학습 리포트 보기"** → AI 분석 레이더 차트 + 약점 개념 + 학습 추천 확인

### AI 역량 진단
7. 상단 네비게이션 **"역량 진단"** 클릭
8. **"React/JavaScript"** 과목 선택 → AI 진단 문제 풀기
9. 결과: 역량 레이더 차트 + 토픽별 피드백 + 추천 강의

---

## 시나리오 3: 멘토 — 이탈 위험 감지 & AI 상담 (2분)

### 로그인
1. 로그아웃 → **이멘토** 로그인

### 멘토 대시보드
2. KPI 카드 4개 (전체/위험/주의/평균 정답률) 확인
3. 위험도 분포 파이 차트 + 3-Signal 현황 바 확인
4. **김민준** (위험, 빨간색 ping 애니메이션) 클릭

### 수강생 상세
5. 3-Signal 시각화 (정답률/응답속도/출석) 확인
6. **"AI 상담 브리핑"** 버튼 클릭 → AI가 생성한:
   - 이탈 위험 판단
   - 대화 포인트 3가지
   - 약점 분석 + 상담 전략
   - 수준 기반 추천 강의
7. 세션별 정답률 추이 LineChart + 토픽별 레이더 차트 확인
8. AI 역량 진단 결과 카드 확인
9. 상담 기록에서 기존 상담 내용 확인 → **"기록 추가"** 버튼

---

## 시나리오 4: 원장 — 경영 대시보드 (2분)

### 로그인
1. 로그아웃 → **박원장** 로그인

### 경영 대시보드
2. KPI 카드 5개 (전체 세션/진행중/수강생/평균 정답률/이탈 위험) 확인
3. 이탈 위험 알림 배너 (빨간색) 확인

### 탭별 확인
4. **개요**: 세션별 정답률 BarChart + 세션 상태 PieChart + 약점 토픽 TOP + 강사별 현황
5. **세션**: 전체 세션 목록 (강사명, 참여자 수, 정답률)
6. **수강생**: 위험/주의/양호 통계 + 전체 수강생 리스트 (SVG 게이지)
7. **수준 분포**: 과목별 수강생 수준 분포 Stacked Bar (입문~전문가)
8. **이탈 관리**: 이탈 위험 수강생 + 3-Signal 레이더

## 핵심 시연 포인트

| 기능 | 설명 | AI 활용 |
|------|------|---------|
| AI 퀴즈 자동생성 | 수업 주제 입력 → 30초 내 코딩 퀴즈 5문제 | Gemini 3 Flash |
| 실시간 이해도 히트맵 | 수강생 응답이 들어올 때마다 자동 갱신 | Supabase Realtime |
| AI 강사 코칭 | 이해도 분석 → 수준별 교수법 제안 | Gemini 3 Flash |
| 피드백 루프 | 보충 설명 후 재퀴즈 → 이해도 변화(델타) 시각화 | 자체 분석 |
| AI 학습 리포트 | 수업 후 개인별 약점 + 학습 경로 자동 생성 | Gemini 3 Flash |
| AI 역량 진단 | 과목별 수준 측정 → 레이더 차트 → 추천 강의 | Gemini 3 Flash |
| 3-Signal 이탈 감지 | 정답률 + 응답 속도 + 출석 복합 분석 | 규칙 기반 |
| AI 상담 브리핑 | 수강생 데이터 → 대화 포인트 + 상담 전략 자동 생성 | Gemini 3 Flash |

## 기술 스택

- **프레임워크**: Next.js 16 (App Router, Server Components)
- **DB/Auth/Realtime**: Supabase (PostgreSQL + RLS + Realtime)
- **AI**: Vercel AI SDK + Gemini 3 Flash (무료 티어, $0)
- **스타일링**: Tailwind CSS v4 + Radix UI
- **차트**: Recharts
- **배포**: Vercel (Edge)
- **바이브코딩**: Claude Code (Opus 4.6, 1M context)
