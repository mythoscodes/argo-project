## Phase 4: 학원 비즈니스 컨텍스트 추가 (신규)

팀장으로부터 중요한 프레임 전환이 공유되었다. 본 프로젝트는 단순 공모전 출품이 아니라 **학원 사업자 관점**에서 실질적으로 활용 가능해야 한다.

### 학원의 핵심 페인포인트 (금전적 관점) -- IT학원 특화로 수정됨
1. **수강생 유지율/중도 포기율** -- 성인 IT교육 중도 포기율 30~50%. 학원 매출 직결
2. **강사 인건비 효율화** -- 강사 1명이 더 많은 학생을 효과적으로 관리 가능해야 함
3. **수강생 수준 편차 관리** -- 비전공자~현직 개발자가 같은 반에 섞이는 문제
4. **경쟁 학원 대비 차별화** -- "이 학원은 AI로 개인 맞춤 교육을 한다"는 마케팅 포인트
5. **운영 비용 절감** -- 시험 출제, 채점, 상담 등 반복 업무의 자동화
6. **취업 연계 압박** -- 수료 후 취업률이 학원 평판과 직결
7. **실습 진도 차이** -- 코딩 실습에서 개인별 진도 차이 관리 어려움

### 수익 모델 방향 (참고)
| 모델 | 설명 | 학원 어필 포인트 |
|---|---|---|
| 학생당 월정액 | 학생 1인당 월 3,000~5,000원 | 학원비에 포함 가능, 학부모 부담 없음 |
| 학원 구독제 | 학원당 월 10~30만원 (학생 수 무관) | 소규모 학원 진입장벽 낮춤 |
| 프리미엄 기능 | 기본 무료 + AI 튜터/리포트 유료 | 학원이 "프리미엄반" 마케팅 가능 |

### 각 팀원별 추가 반영 요청 (IT학원 타겟으로 수정됨)
- **market-analyst**: IT학원 시장(국비지원, 부트캠프 등) 관점으로 차별화 재정리

## Phase 5: 팀장 최종 결정 (확정)

### 확정 아이디어: EduLens + 피벗B (교강사 AI 코칭) + 성인 IT학원 비즈니스 모델

### 최종 포지셔닝 (수정됨)
> ~~"AI가 교강사를 실시간으로 코칭하는 학원 맞춤 교육 솔루션"~~
> → **"AI가 IT강사를 실시간으로 코칭하는 성인 IT교육 솔루션"**

### 타겟 사용자 (긴급 수정)
1. **IT학원 강사** (교강사) -- 코딩/개발 수업 진행
2. **성인 수강생** -- 직장인/취준생/전직자 등 IT 교육 수강자
3. **학원 원장/운영자** -- 수강생 유지율 및 취업률 관리
- ~~학부모~~ → **전면 삭제** (성인 수강생이므로 불필요)

### 결정 근거
1. **시장 차별화가 공모전에서 가장 중요** -- "왜 기존 서비스 안 쓰나요?"라는 질문이 나오지 않는 유일한 아이디어 (market-analyst, critic 동의)
2. **critic의 3가지 조건을 필수 가드레일로 채택**:
   - 교강사 대시보드에 80% 집중, 학생 뷰는 퀴즈 입력 UI만
   - 데이터 입력 방식 = **수업 중 실시간 미니퀴즈** (확정)
   - 데모 시나리오 먼저 설계 → 역산으로 기능 결정
3. **하이브리드는 채택하지 않음** -- critic 의견 수용. "한 문장으로 설명 가능한 정체성" 유지가 중요
4. **IT학원 비즈니스 관점 반영** -- 수강생 본인 학습 리포트, 중도 포기율 감소, IT학원 마케팅 차별화

### 확정 데이터 소스 (수정됨)
1. **코드 스니펫 퀴즈** (MVP 핵심) -- "이 코드의 출력은?", "버그를 찾아라", "빈칸 채우기(코드)" 형태. AI가 수업 중 코드 예제 기반 자동 생성.
2. **간단한 코드 제출 + 실행 결과** (MVP 포함 가능 시) -- 수강생이 코드 제출 → 자동 실행 → 통과/실패를 이해도 데이터로 활용. tech-architect 판단에 따라 MVP 포함 여부 결정.
3. **코딩 실습 실시간 모니터링** -- MVP 제외. Phase 2 로드맵.

### 확정 데모 플로우 (6단계, 수정됨)
1. IT강사가 수업 세션 시작
2. AI가 수업 중 코드 예제 기반 **코드 스니펫 퀴즈** 자동 생성
3. 수강생이 모바일로 실시간 응답
4. 이해도 히트맵이 강사 대시보드에 실시간 갱신
5. AI가 강사에게 코칭 제안 ("이 개념에서 60%가 약합니다. 보충 설명 권장")
6. 수업 후 **수강생 본인에게** 학습 리포트 자동 발송

### 확장 내러티브 (발표용)
> "IT학원에서 시작하지만, '실시간 이해도 분석 + 강사 AI 코칭' 엔진은 모든 교육 환경에 적용 가능합니다."
